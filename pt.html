PROJETOS ACADÉMICOS

ELETROSYNC – SISTEMA DISTRIBUÍDO DE COMPARAÇÃO DE PREÇOS

💻 github.com/RubenPereira2005/EletroSync | 🚀 Live Demo: eletrosync.site

  • Plataforma de agregação de preços em tempo real com arquitetura distribuída de baixa latência.
  • Implementação do padrão Scatter-Gather para consultas concorrentes e assíncronas a múltiplas APIs em simultâneo.
  • Desenvolvimento de cache persistente (JSON) com TTL adaptativo e otimização de rotas via Rate Limiting.
  • Mecanismos de resiliência com timeouts, isolamento de falhas (AbortController) e proteção contra thundering herd.
  • Autenticação e segurança de dados com Supabaseatravés de políticas estritas de Row Level Security (RLS).
  • Tecnologias: Node.js, Express, Supabase (PostgreSQL), Serper API, Resend, Docker, Render.
SIMULAÇÃO DE REDE WAN/LAN SEGURA & ACL ESTENDIDA

💻 github.com/Rodrigosbessa/cisco-packet-tracer-wan-acl

  • Projeção e configuração de uma arquitetura de rede fim-a-fim ligando uma Home LAN privada a um Datacenter público através de múltiplos ISPs no Cisco Packet Tracer.
  • Implementação de NAT Overload (PAT) na fronteira para tradução de endereços e proteção da sub-rede privada.
  • Configuração de Encaminhamento Estático por Defeito otimizado nos routers Home, ISP_1 e ISP_2.
  • Aplicação de controlo de tráfego rigoroso através de uma ACL Estendida com base no Princípio do Menor Privilégio, permitindo tráfego DNS, HTTP/HTTPS e ICMP, e bloqueando acessos remotos não autorizados (Telnet/SSH).
  • Tecnologias: Cisco Packet Tracer, Cisco IOS, ACLs Estendidas, NAT/PAT, Sub-redes IPv4, Encaminhamento.
SISTEMA DE FATURAÇÃO (FATURIX.ORG)

💻 github.com/Rodrigosbessa/faturacao | 🚀 Live Demo: faturix.org

  • Desenvolvimento e melhoria contínua de um sistema de faturação web, atualmente em produção e acessível online, permitindo a emissão de faturas, guias de remessa e recibos.
  • Desenvolvido com Django (Python), alojado no Render, com base de dados PostgreSQL gerida via Neon.
  • Domínio próprio gerido através da Cloudflare, com implementação de autenticação de dois fatores (MFA) utilizando a API da Twilio.
  • Sistema concebido para ambiente não certificado, sem integração direta com a Autoridade Tributária (software de faturação não certificado).
